# Additional generated samples

`original.lua` is a benign two-line test payload. The other files are actual
generated output, not synthetic producer headers:

- `luaseel.lua`: generated by `Obfuscate(original)` in
  [Direnta/LuaSeel](https://github.com/Direnta/LuaSeel/tree/2f46b9fd71165a791fa44e0a29e08e9ec0c4bf71), `obfuscator.lua`.
  Only the generator function was loaded, replacing `print` with an output capture.
- `xfuscator_step2.lua`: generated by calling the function returned from
  [efrederickson/XFuscator](https://github.com/efrederickson/XFuscator/tree/7e58176d3fe3cd9349c64652c61fed1cf2092fa1),
  `XFuscator/Step2.lua`, with the original payload and default options.
  This covers Step2 packing, not all XFuscator configurations.

Both generators were run using Lupa's Lua 5.1 runtime. The regression tests
verify detection, complete payload capture, and unchanged sandbox behavior.
